# Contributing to Awesome React Native Libraries

Thank you for your interest in contributing to Awesome React Native Libraries! This document provides guidelines for contributing.

## How to Contribute

### Reporting Issues

If you find a library that should be added, removed, or updated, please open an issue with:
- A clear title and description
- Link to the library
- Reason for the change

### Submitting Pull Requests

1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-library`)
3. Add your changes following the existing format
4. Commit your changes (`git commit -m 'Add amazing library'`)
5. Push to the branch (`git push origin feature/amazing-library`)
6. Open a Pull Request

## Guidelines

- Follow the existing format and structure
- Ensure all links are working
- Add libraries to the appropriate category
- Include a brief description for each library
- Keep descriptions concise and informative

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for contributing!
